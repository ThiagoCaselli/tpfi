# Installation

## Stable release

To install TPFI, run this command in your terminal:

```sh
uv add tpfi
```

Or if you prefer to use `pip`:

```sh
pip install tpfi
```

## From source

The source files for TPFI can be downloaded from the [Github repo](https://github.com/ThiagoCaselli/tpfi).

You can either clone the public repository:

```sh
git clone https://github.com/ThiagoCaselli/tpfi
```

Or download the [tarball](https://github.com/ThiagoCaselli/tpfi/tarball/main):

```sh
curl -OJL https://github.com/ThiagoCaselli/tpfi/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd tpfi
uv sync
```
